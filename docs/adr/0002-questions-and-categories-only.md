# Questions and categories only, no quizzes

The question converter only produces questions and their categories. Quiz activities (time limits, question selection, random questions, review options) can't be expressed in Moodle XML; generating them would mean writing Moodle course backups (`.mbz`), an internal format that changes between Moodle versions. Lecturers assemble quizzes from the imported categories in Moodle, which is quick once the question bank is well organised.
